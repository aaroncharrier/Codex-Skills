# Quest: First Pipeline Expedition

## Mission Briefing

Build a small but real data engineering project using the project scaffold workflow, then turn that scaffold into a working practice base we can keep expanding. The goal is not to rush to code. The goal is to set up a project that teaches good delivery habits and creates space for repeatable progress.

## Why This Quest Matters

- It turns a vague project idea into a durable workspace with planning and operating rules.
- It practices both technical project setup and healthy Codex collaboration.

## Quest Classification

`new project quest`

## Build Stages

1. Bootstrap the project under `Codex Improvement\<tutorial name> yyyy_mm_dd`.
2. Complete `docs\questionnaires\AGENTS.QUESTIONNAIRE.md` and update `AGENTS.md`.
3. Run `project-initiation-pm` to create the first real planning draft.

## Checkpoints

- The scaffold exists in the correct location.
- `AGENTS.md` reflects the completed questionnaire.
- `docs\PROJECT_PLAN.md` and `docs\WORK_LOG.md` contain a credible first draft.

## Acceptance Criteria

- The project follows the required three-phase workflow.
- The user can explain the project's goal, operating model, and next work item.

## Stretch Goals

- Add one starter implementation task to the backlog.

## Evidence To Bring Back

- The final project path
- A short note on what changed in `AGENTS.md`
- The first next-action item from `docs\PROJECT_PLAN.md`

## Quest-Wiki Updates

- Create or update the campaign file for the project.
- Add follow-up ideas to the backlog.
- Record any learner strengths or friction points in growth notes.
